# 🔒 Security Policy

## Supported Versions

| Version   | Supported |
| --------- | --------- |
| 1.0.x     | ✅         |
| Below 1.0 | ❌         |

---

## Reporting a Security Issue

If you discover a security vulnerability:

* Do not publish it publicly.
* Open a private security report through GitHub Security Advisories.

Include:

* Description
* Steps to reproduce
* Impact
* Suggested fix

We'll investigate and release a fix as quickly as possible.

Thank you for helping keep NOX secure.
