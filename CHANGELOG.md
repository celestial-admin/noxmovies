# [1.0.0] — Stable Release

**Release Date:** August 2026

The first stable public release of NOX Movies introduces the foundation of the cinematic Android experience.

## ✨ Added

### UI & Experience

* Brand-new cinematic Material 3 interface.
* AMOLED optimized dark theme.
* Premium movie cards and hero banners.
* Smooth Compose animations.
* Responsive layouts for Android devices.

### Navigation

* Home Screen.
* Search Screen.
* Movie Details Screen.
* Bottom Navigation.
* Favorites Screen.
* Downloads Screen.

### Playback

* AndroidX Media3 integration.
* Full-screen player.
* Playback controls.
* Continue Watching support.
* Subtitle-ready player architecture.

### Search

* Debounced local search.
* Trending movie discovery.
* Category browsing.
* Placeholder recommendation engine.

### Library

* Favorites support.
* Watch History.
* Download Manager UI.
* Local movie repository.

### Architecture

* MVVM architecture.
* Kotlin Coroutines.
* Compose Navigation.
* Reusable UI components.
* Theme system for NOX branding.

---

## 🎨 Design

* Introduced NOX design language.
* AMOLED-first color palette.
* Editorial spacing system.
* White + Soft Pink accent styling.

---

## ⚙️ Developer Experience

* Modular project structure.
* Clean repository architecture.
* Gradle build configuration.
* Coil image loading support.

---

## 🚧 Known Limitations

* Download engine uses placeholder implementation.
* Authentication is not available yet.
* Backend APIs are mocked.
* Recommendation system is local only.
