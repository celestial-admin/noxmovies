# 🤝 Contributing to NOX Movies

Thank you for considering contributing to NOX Movies.

We welcome improvements, bug fixes, and new ideas.

## Getting Started

1. Fork this repository.
2. Clone your fork.
3. Create a new branch.

```bash
git checkout -b feature/your-feature
```

4. Make your changes.
5. Commit.

```bash
git commit -m "feat: add new feature"
```

6. Push and create a Pull Request.

---

## Coding Guidelines

* Kotlin style conventions.
* Use Jetpack Compose.
* Follow MVVM architecture.
* Keep reusable UI components inside `ui/components`.

---

## Pull Request Checklist

* Code builds successfully.
* No unnecessary files.
* UI matches NOX design language.
* Feature is documented if needed.

---

## Reporting Bugs

Open a GitHub Issue and include:

* Device
* Android Version
* App Version
* Screenshots
* Steps to reproduce
